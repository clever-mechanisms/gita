# Security policy

## Supported versions

Gitā is in its 0.x series. Security fixes go into the latest release only; there are no backports to earlier
releases. Update to the newest release from the GitHub Releases page before you report an issue.

| Version | Security fixes |
| --- | --- |
| Latest release (currently 0.2.x) | Yes |
| Earlier releases | No |

## Reporting a vulnerability

Do not report vulnerabilities in public GitHub issues, pull requests or discussions.

Report them privately by email to **support@clevermechanisms.dev**. Include:

- your Gitā version and macOS version;
- the affected feature, such as history, commits, remotes, the GitHub, Vercel or Orca integration, coding-agent hooks
  or the built-in terminal;
- what an attacker can do and what they need to do it;
- enough detail to reproduce the issue: steps, a sample repository or configuration, and logs or screenshots.

We will acknowledge your report, keep you informed while we work on a fix, and credit you in the release notes
unless you prefer otherwise. Please keep the details private until a fixed release is available.
